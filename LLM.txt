Holdem — The free Dropover for Windows.
Floating shelf to stash files mid-drag: shake while dragging, drop, navigate, drag out.
Stack: Tauri 2.x + Rust backend + React 19 + TypeScript + Vite + Tailwind. Windows 10/11 x64 only.
Site: https://holdem.iamzub.in. Releases: https://github.com/iamzubin/holdem/releases.
Version: 3.1.1 (master, 2026-09-05). License: MIT.

REPO LAYOUT
- app/              Tauri desktop app (the product)
  - src/            React frontend: App.tsx, PopupWindow.tsx, main.tsx, types.ts
  - src/            components/ (FileIcon, StackedIcons, theme-provider, ui/*)
  - src/            hooks/useFileManagement.ts, lib/{fileUtils,utils,windowUtils}.ts
  - src/            pages/{Consent,Settings,Updater}.tsx, i18n/{index.ts,locales/*.json (25 locales)}
  - src-tauri/      Rust backend: src/{lib,main,config,file,file_drop,drop_target,thumbnail,tray,analytics,logging,utils}.rs
  - src-tauri/      src/{commands/{config_ops,drag_ops,file_ops,window_ops},mouse_monitor/{mod,win}}.rs
  - src-tauri/      tauri.conf.json (productName holdem, id com.holdem.desktop, 165x175 always-on-top window)
  - package.json, vite.config.ts, tailwind.config.js, tsconfig.json
- holdem_website/   Next.js 15 + React 19 + Tailwind 4 marketing site (port 3000)
- assets/           README demo gif + icons
- .github/workflows/{opencode,opencode-review}.yml, .opencode/commands/, AGENTS.md, agent.md, CHANGELOG.md, crowdin.yml

COMMANDS
- app: cd app && npm install; npm run build (tsc + vite); npm run tauri dev; npm run tauri build (installer)
- app Windows-only build: npm run build:windows (x86_64-pc-windows-msvc)
- rust: cd app/src-tauri && cargo build; cargo test <name>; cargo clippy -- -D warnings (run before committing)
- website: cd holdem_website && npm install; npm run dev (:3000); npm run build / start / lint; npx prettier --write .
- Do not run app `npm run dev` in agent sessions (user handles it).

CONVENTIONS (from AGENTS.md)
- Files kebab-case; components PascalCase; functions/variables camelCase.
- Imports via `@/*` (= ./src/*); merge classes with cn() (clsx + tailwind-merge).
- Prefer `interface` for shapes, `type` for unions. Radix UI primitives for a11y components.
- Rust: explicit signatures, thiserror + Result<T, Error>, AsRef<Path> for path args.
- Tauri: add #[tauri::command] in src-tauri/src/lib.rs, call via invoke() from frontend.
- Tailwind differs: 3.x in app/, 4.x CSS-based config in holdem_website/.
- thumb-rs submodule is reference only; app uses its own port in src-tauri/src/thumbnail.rs.

KEY BEHAVIOR / INTEGRATIONS
- Summon: mouse-shake-while-dragging (mouse_monitor) or global hotkey; window hides when empty.
- Drops: native Windows OLE target (drop_target.rs, file_drop.rs) — Explorer files/folders + browser images/URLs/text.
- Tray (tray.rs): settings, quick actions, auto-launch + auto-update (updater endpoints: holdem.iamzub.in/update.json + github latest.json).
- i18n: i18next, 25 locales, browser-locale detection, RTL support; translations via Crowdin (crowdin.yml).
- State: useFileManagement hook is source of truth for shelf contents; PopupWindow is the shelf UI.

CI / AGENTS
- opencode.yml = builder (auto-commits); opencode-review.yml = read-only reviewer (max 5 High/Medium findings).
- agent.md: CI agents must not commit/push unless the triggering comment explicitly asks; keep `git status --short` clean; never touch dist/, lockfiles, generated files unless required.
- Contributing: run cargo clippy + npm run build before PR; updater manifest (holdem_website/public/update.json) synced manually after release.
